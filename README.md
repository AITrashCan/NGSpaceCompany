# 天道长生录

修仙题材放置类游戏——从凡俗小镇起步，逐步开辟灵脉、探索秘境、游历仙域，最终渡劫飞升、参悟天道。

本项目基于 NG Space Company 进行修仙题材重制，采用 Vue 3 + Vuex 4 + Bootstrap 5 构建。

---

## 原项目信息

NG Space Company — Incremental space game about resource mining, interstellar exploration and system conquest.

This game has been made as a remake of the original game from Sparticle999. Of course I have the authorization from Sparticle999 to do it. I made this game to improve my skills in VueJS and to get knowledge about incremental games.

## 开发

```bash
npm install
npm run serve   # 开发服务器（热重载）
npm run build   # 生产构建
npm run lint    # ESLint 检查
```

## 技术栈

- Vue 3 + Vuex 4
- Bootstrap 5
- vue-i18n（中/英/法三语）
- Vite
